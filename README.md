# Günüm (My Day)

A simple daily planner that runs in the browser and can be installed on a phone like an app (PWA). The interface is in Turkish.

- Daily tasks and routines that come back every day
- Medication and vitamin reminders
- Plan tasks for future dates; overdue tasks are shown separately
- Last 7 days summary and streak
- Backup and restore for changing devices

## Run
`node server.js`, then open http://localhost:4173

## Privacy
Everything is stored only on your own device (browser storage). Nothing is sent to a server.

Built with the help of an AI coding assistant as part of my learning journey.
